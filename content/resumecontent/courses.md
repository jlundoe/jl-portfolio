#### 2022
### Audiokinetic Certificate Courses
##### Wwise 301 Certification Course
<span>Wwise Unity Integration</span><br>
A course covering the integration between Wwise and Unity and all the tools necessary to implement audio and music from Wwise into the Unity game engine.
- Key concepts in the design and implementation of interactive and spatial audio.

##### Wwise 201 Certification Course
<span>Interactive Music</span><br>
A course covering the implementation of dynamic music using Wwise. It is focused on both the creative and technical aspects and challenges in interactive composition.
- Key concepts of interactive music and its implementation in software.

##### Wwise-101 Certification Course
<span>Interactive Audio</span><br>
A course covering fundamental Wwise features and workflows for setting up interactive audio, preparing it for implementation.
- Key concepts in interactive and spatial audio and its implementation in software.
- Comprehensive understanding of the implementation tool Wwise
